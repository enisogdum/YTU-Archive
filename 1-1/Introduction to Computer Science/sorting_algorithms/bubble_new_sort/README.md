# Bubble Sort (New Version)

This folder contains the **new (optimized) version** of the Bubble Sort algorithm implemented in C.

## Files

| File | Description |
|------|-------------|
| `bubble_sort.c` | C source code for the optimized bubble sort implementation |
| `bubble_sort` | Compiled binary |
| `bubble_sort.dSYM/` | Debug symbol directory (auto-generated by compiler) |

## Algorithm

Bubble Sort works by repeatedly stepping through the list, comparing adjacent elements and swapping them if they are in the wrong order. The **new version** includes an early-exit optimization — it stops if no swaps occurred in a pass, meaning the list is already sorted.

**Time Complexity:** O(n²) worst case, O(n) best case (optimized)  
**Space Complexity:** O(1)
