# Bubble Sort (Old Version)

This folder contains the **original (classic) version** of the Bubble Sort algorithm implemented in C.

## Files

| File | Description |
|------|-------------|
| `bubble_sort.c` | C source code for the classic bubble sort implementation |
| `bubble_sort` | Compiled binary |
| `bubble_sort.dSYM/` | Debug symbol directory (auto-generated by compiler) |

## Algorithm

Bubble Sort works by repeatedly stepping through the list, comparing adjacent elements and swapping them if they are in the wrong order. The **old version** always runs through all passes regardless of whether any swaps occurred.

**Time Complexity:** O(n²)  
**Space Complexity:** O(1)
