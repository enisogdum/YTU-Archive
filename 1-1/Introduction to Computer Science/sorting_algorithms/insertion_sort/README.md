# Insertion Sort

This folder contains the **Insertion Sort** algorithm implemented in C.

## Files

| File | Description |
|------|-------------|
| `insertion_sort.c` | C source code for the insertion sort implementation |
| `insertion_sort` | Compiled binary |
| `insertion_sort.dSYM/` | Debug symbol directory (auto-generated by compiler) |

## Algorithm

Insertion Sort builds the sorted array one element at a time by picking each element and inserting it into its correct position among the previously sorted elements.

**Time Complexity:** O(n²) worst case, O(n) best case  
**Space Complexity:** O(1)
