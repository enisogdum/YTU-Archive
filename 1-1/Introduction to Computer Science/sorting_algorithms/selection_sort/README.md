# Selection Sort

This folder contains the **Selection Sort** algorithm implemented in C.

## Files

| File | Description |
|------|-------------|
| `selection_sort.c` | C source code for the selection sort implementation |
| `selection_sort` | Compiled binary |
| `selection_sort.dSYM/` | Debug symbol directory (auto-generated by compiler) |

## Algorithm

Selection Sort works by dividing the list into a sorted and an unsorted region. It repeatedly finds the minimum element in the unsorted region and moves it to the end of the sorted region.

**Time Complexity:** O(n²)  
**Space Complexity:** O(1)
