# Lab 4 — Structured Programming (2026)

Fourth lab session for the **Structured Programming** course (2026). This lab involves **music/songs management** using file I/O and binary files.

## Files

| File | Description |
|------|-------------|
| `tanım.md` | Lab assignment description (in Turkish) |
| `kod.c` | C source code solution |
| `kod` | Compiled binary |
| `kod.dSYM/` | Debug symbol directory (auto-generated) |
| `songs.txt` | Song list (text input format) |
| `songs.dat` | Songs database (binary file) |
| `skipped.txt` | Output file for skipped entries |
